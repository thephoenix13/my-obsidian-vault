## Plan for Supper Club
- [ ] Define concept and theme
- [ ] Shortlist venue or hosting location
- [ ] Curate guest list
- [ ] Plan menu (courses, dietary restrictions)
- [ ] Set date and frequency (one-time or recurring)
- [ ] Arrange logistics (seating, serving, ambience)
- [ ] Budget and cost per head
- [ ] Follow-up and feedback after first event

## Plan for Jobs
- [ ] Define target roles and industries
- [ ] Update resume and LinkedIn profile
- [ ] Shortlist companies to apply to
- [ ] Reach out to network for referrals
- [ ] Prepare for interviews (common questions, portfolio)
- [ ] Set weekly application targets
- [ ] Track applications and follow-ups
- [ ] Evaluate and negotiate offers

## Plan for Consulting
- [ ] Define consulting niche and service offering
- [ ] Identify target client profile
- [ ] Set pricing model (hourly, retainer, project-based)
- [ ] Build a simple portfolio or case studies
- [ ] Create outreach plan (LinkedIn, referrals, cold email)
- [ ] Draft a consulting agreement template
- [ ] Set up invoicing and payment process
- [ ] Land first 2–3 clients

## Diet Plan
- [ ] Define goal (weight loss, muscle gain, energy, etc.)
- [ ] Consult nutritionist or research suitable diet type
- [ ] Plan weekly meals (breakfast, lunch, dinner, snacks)
- [ ] Create grocery list template
- [ ] Set daily water intake target
- [ ] Track meals and progress weekly
- [ ] Identify cheat meal rules
- [ ] Review and adjust plan every 4 weeks
