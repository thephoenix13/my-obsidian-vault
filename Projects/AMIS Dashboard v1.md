# AMIS Dashboard v1

## Overview
Modern web-based dashboard and admin interface for the AMIS (Attendance Management Information System). Built on Lovable platform with a comprehensive component library.

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- Supabase (backend & auth)
- TanStack Query
- Recharts (data visualization)
- Playwright (E2E testing)
