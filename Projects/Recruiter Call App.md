# Recruiter Call App

## Overview
A browser-based calling platform with live AI transcription designed for recruiters. Full-stack application with real-time communication via Socket.io and Deepgram for speech-to-text transcription.

## Tech Stack
- **Frontend:** React, Twilio Voice SDK
- **Backend:** Node.js, Express, Socket.io
- **AI/Transcription:** Deepgram (WebSocket)
- **Infrastructure:** ngrok (tunneling)

## Status
Active — fully functional with setup scripts and comprehensive documentation.

## Features
- Browser-based VOIP calling (Twilio)
- Live call transcription (Deepgram)
- Real-time updates (Socket.io)
- ngrok tunnel for local dev
