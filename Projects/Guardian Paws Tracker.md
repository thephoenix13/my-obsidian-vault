# Guardian Paws Tracker

## Overview
A web-based pet and animal tracking/management application with PDF document generation capabilities. Built on Lovable platform with Supabase backend.

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- Supabase
- jsPDF, jsPDF-AutoTable (PDF generation)

## Status
Active development.

## Features
- Animal/pet tracking and management
- PDF report generation
- Supabase backend
