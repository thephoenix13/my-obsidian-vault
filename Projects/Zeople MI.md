# Zeople MI — Market Intelligence

## Overview
A market intelligence and management interface module with data analysis, visualization, and spreadsheet export capabilities.

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- Supabase
- Recharts (visualization)
- XLSX, jszip (data export)

## Status
Active development.

## Features
- Market intelligence dashboards
- Data visualization (Recharts)
- Export to Excel/ZIP
- Supabase backend
