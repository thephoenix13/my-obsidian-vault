# CBK Infra

## Overview
A dashboard and reporting-focused web application with OpenAI integration, multilingual support, and data export capabilities (Excel/ZIP).

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- OpenAI
- i18next (multilingual)
- XLSX, jszip (data export)
- Supabase

## Status
Active development.

## Features
- Dashboard & reporting UI
- AI-powered features (OpenAI)
- Data export to Excel and ZIP
- Internationalization support
