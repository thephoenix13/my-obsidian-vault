# Propel AI App

## Overview
A voice communication application powered by Twilio Voice SDK with document generation and export capabilities.

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- Twilio Voice SDK
- Supabase
- docx, file-saver (document export)

## Status
Active development.

## Features
- Browser-based voice communication (Twilio)
- Document generation (DOCX)
- File export capabilities
