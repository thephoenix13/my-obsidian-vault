# Zeople ATS — Applicant Tracking System

## Overview
A full-featured Applicant Tracking System (ATS) for recruitment teams. Includes role-based component system and standard HR/recruitment dashboard UI.

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- TanStack React Query

## Status
Active development.

## Features
- Applicant tracking & management
- Role-based access
- Recruitment pipeline dashboard
