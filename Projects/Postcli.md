# Postcli

## Overview
A Python CLI tool for sending handcrafted, templated emails directly from the terminal. Supports CSV-based contact management, Jinja2 templates, and SMTP integration.

## Tech Stack
- Python 3.9+
- Jinja2 (templating)
- SMTP
- CSV contact management

## Status
Active — published project with comprehensive documentation and usage examples.

## Features
- Send emails from terminal
- Jinja2 email templates
- CSV contacts import/export
- JSON to CSV conversion

## Notes
- Utility tool, not a web app
- Useful for outreach campaigns and bulk personalized emails
