# KMPL RMS — Resource Management System

## Overview
A multi-level role-based Resource Management System (RMS) with a hierarchical dashboard for managing operations across different organizational levels.

## Tech Stack
- React 18, TypeScript
- Vite
- shadcn/ui, Tailwind CSS
- Supabase (auth, database, edge functions)
- TanStack React Query
- React Router
- Sonner (notifications)

## Status
Active development — recent builds as of April 24, 2026.

## Roles
- Operations Manager
- Area Manager
- Field Supervisor
- And other organizational roles

## Features
- Role-based access control (RBAC)
- Multi-level hierarchy dashboard
- Supabase edge functions

## Notes
- Enterprise-grade RMS with full auth and database via Supabase
